# paper2signature

A reproducible pipeline for literature-based discovery, extraction, and curation of biological gene signatures.

**paper2signature** provides a collaborative framework for querying scientific publications, identifying relevant biological signatures, and supporting LLM-assisted information extraction and standardization.

The repository aims to improve reproducibility, streamline literature mining, and facilitate integration of curated signatures into downstream computational analyses.

## Acknowledgments 

This project builds upon the original paper-query workflow developed at the BHK Lab (https://github.com/bhklab/query_papers).

The current repository aims to extend this work through improved code organization, reproducible environment management using Pixi, and integration with downstream signature extraction and validation workflows.
